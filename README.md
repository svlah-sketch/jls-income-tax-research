# Croatia local income-tax research: prospective analysis plan

This is a separate project for research on Croatian local income-tax choices after surtax abolition. It records a prepared analysis plan for two new exploratory analysis families before their first estimation:

1. **N2:** mechanical correspondence between proportional statutory schedules and changes in reported effective withholding rates, including a pension sensitivity.
2. **Budget weight:** association between the local budget share of income-tax receipts and upward departures from national rates.

The optional holiday-home analysis N9 is documented but **not activated** for the first execution.

## Publication and execution record

The first public commit containing all these files will identify the deposited version. Record its exact commit URL, SHA and publication evidence before running either new analysis family. Preserve this version. Any change to the plan must appear as a dated amendment before the affected computation.

The broader study is exploratory and many previous outcomes have already been inspected. A prospective record of these two new families does not retrospectively preregister the earlier study and does not make these associations causal. No new-family model has been estimated at package preparation.

This repository initially contains the protocol, design benchmarks and hashes. The manuscript, full research archive and raw-data snapshots are outside the scope of this initial publication.
